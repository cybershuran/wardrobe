# Wardrobe · 衣橱

个人电子衣橱：极简画廊风格的本地网页应用。

- 打开 `我的衣橱.html` 即可使用（需和 `images/` 文件夹在同一目录）
- 分类浏览 / 单品详情（色板、笔记）/ 手动搭配保存 OUTFIT
- 可选 AI 搭配：在 OUTFITS 页底部填入 OpenAI 兼容接口的 Key（支持自定义 API 地址）

灵感来源：[tandpfun/wardrobe](https://github.com/tandpfun/wardrobe) 与 [wardrobe-vibe](https://wingchunsiu.github.io/wardrobe-vibe/)
